# NetScope

**NetScope** is a Windows network utility application developed with C# and Windows Forms.

It provides useful tools for checking network information, testing connectivity, calculating IP subnets, and measuring internet speed.

## Features

* 🌐 Network Information
* 📡 Ping Test
* 🧮 IP Subnet Calculator
* 🚀 Internet Speed Test
* 🌍 Turkish / English Language Support
* 🔊 Interface Sound Effects
* 💻 Windows Forms Interface

## Requirements

* Windows 10 or later
* x64 system
